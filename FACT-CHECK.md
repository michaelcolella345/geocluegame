# GeoClue fact-check: puzzles 2026-10-13 to 2026-12-11

I checked every clue and "Did you know?" fact in all 60 puzzles (30 written by Michael, 30 by Claude). Nearly everything is well established. **This list covers only the items worth a second look**, ordered by date so you can work through it alongside `data/puzzles.json`.

How to read it:

- **Check**: I'm not fully confident. Please verify before that date.
- **Watch**: it's true now, but could go out of date. Re-check if you reuse the puzzle later.
- **Changed**: I reworded one of your clues. The original is shown so you can put it back if you like.

All source links point to English Wikipedia articles. I spot-checked the ones I was least sure of. The rest are standard article titles but haven't each been opened, so a click-through on a few is worthwhile.

## Things I verified online (October 2026)

- **Brazil, clue 3** (five World Cups, the most of any country) is still true. Spain won the 2026 World Cup final against Argentina, so Brazil's total stayed at 5.
- **Finland, Did you know** (top of the World Happiness Report every year since 2018) is still true. The March 2026 report made it nine years in a row.
- **Italy, clue 2** (most UNESCO sites) is still true but close: Italy has 62 and China 61 as of 2026. *Watch.*
- **Norway, clue 2** (largest sovereign wealth fund) is still true at about $2.3 trillion in mid-2026. *Watch.*
